# Construyendo Sueños

## Descripción
Sitio web de una empresa constructora desarrollado como parte de la práctica
"Aplicación de estilos y propiedades CSS" de la asignatura Fundamentos de Sistemas Web.

## Tecnologías utilizadas
- HTML5
- CSS3 (hoja de estilos externa `css/estilos.css`)
- Git
- GitHub

## Funcionalidades
- Encabezado con logo, imagen de fondo, navegación y cifras de la empresa.
- Sección "Quiénes somos" con misión, visión, valores e imágenes que funcionan como enlaces.
- Tarjetas de servicios y lista del proceso de trabajo.
- Tabla de proyectos realizados y en ejecución.
- Galería de seis imágenes con efectos `:hover`.
- Sección "Seguridad en obra" (reto).
- Formulario de cotización con estilos `:focus` y `:active`.
- Enlaces internos, enlaces externos e imágenes que funcionan como enlaces.

## Conceptos CSS aplicados
- Selectores: universal, etiqueta, clase, ID, agrupado, descendiente, hijo directo, hermano adyacente y hermanos generales.
- Pseudoclases: `:hover`, `:active`, `:focus`, `:first-child`, `:last-child` y `:nth-child()`.
- Colores en formato HEX, RGB y HSL.
- Propiedades de fuentes, texto, fondos, bordes, márgenes, padding y dimensiones.

## Ramas del repositorio
- `main`: versión final.
- `desarrollo`: integración de funcionalidades.
- `despliegue`: versión validada.
- `funcionalidad-inicio`: encabezado, navegación y presentación.
- `funcionalidad-servicios`: servicios, proyectos, galería y contacto.
- `funcionalidad-reto`: sección "Seguridad en obra".
