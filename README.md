# Construyendo Sueños

## Descripción
Sitio web de una tienda de herramientas desarrollado como parte de la práctica
"Aplicación de estilos y propiedades CSS" de la asignatura Fundamentos de Sistemas Web.

## Tecnologías utilizadas
- HTML5
- CSS3 (hoja de estilos externa)
- Git
- GitHub

## Funcionalidades
- Presentación de la tienda y sus ventajas.
- Navegación entre secciones mediante enlaces internos.
- Tarjetas de servicios (alquiler, asesoría, mantenimiento y entrega).
- Tabla de productos y precios.
- Galería de seis imágenes con efectos `:hover`.
- Sección "Seguridad en la obra" (reto).
- Formulario de contacto con estilos `:focus` y `:active`.
- Enlaces externos e imágenes que funcionan como enlaces.

## Conceptos CSS aplicados
- Selectores: universal, etiqueta, clase, ID, agrupado, descendiente, hijo directo, hermano adyacente y hermanos generales.
- Pseudoclases: `:hover`, `:active`, `:focus`, `:first-child`, `:last-child` y `:nth-child()`.
- Colores en formato HEX, RGB y HSL.
- Propiedades de fuentes, texto, fondos, bordes, márgenes, padding y dimensiones.

## Ramas del repositorio
- `main`: versión final.
- `desarrollo`: integración de funcionalidades.
- `despliegue`: versión validada.
- `funcionalidad-inicio`: encabezado, navegación y presentación.
- `funcionalidad-servicios`: servicios, productos, galería y contacto.
- `funcionalidad-reto`: sección "Seguridad en la obra".
